# pf1-endless-framework

A planned set of connected Foundry VTT modules for Pathfinder 1e: a shared core, the PF1 Check Requester, items and merchants (with Item Piles and alternate currencies), settlements, NPCs and relationships, factions, research, and more. Each module works on its own and does more when the others are installed.

Nothing is built yet. The concept is in [`docs/CONCEPT.md`](docs/CONCEPT.md).
